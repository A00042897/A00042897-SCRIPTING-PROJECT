# A00042897-SCRIPTING-PROJECT
Scenario 1 - Security Log investigation 

HOW TO RUN SCRIPT 

Start the terminal
-when menu is presented select
     1.FIREWALL.LOG ANALYSIS
          The output will be a complete analysis on firewall.log
     2.AUTHENTICATION.LOG ANALYSIS
          The output will be a complete analysis on Authentication.log
     3.RUN FULL ANALYSIS
           The output will be a combination of firewall.log analysis and authentication.log analysis
     4.GENERATE REPORT
           Will create a document called "final_report.txt" containing the full analysis 
     5.EXIT MENU
           This will exit the menu. Run the terminal again to select from the options
